# travel_staysphere_hotel_booking_platform
Microservices-based hotel booking platform built with Spring Boot, React, MongoDB, Kafka, Redis and Docker. Features JWT security, API Gateway, Eureka discovery, Resilience4j, atomic room availability locking and saga-based payment flow.

StaySphere is a scalable, event-driven travel and hotel booking platform where users can search stays, book rooms, pay securely and review their trips, built with a Java Spring Boot microservices backend and a React frontend.
